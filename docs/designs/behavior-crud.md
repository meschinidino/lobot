## Vision

### 10x Check
One direction per trait powers four verbs. Create a trait from a sentence, Read it live per token, Update it with a dose, Delete it by ablation, each with a report card. A prompt can change behavior; it cannot read the model's internal state. Read is the part no prompt can do, and Update is measured against a plain prompt on screen.

### Platonic Ideal
Pick a model and its trait fingerprint appears. Type "sycophantic" and a new dial appears with its proof (about 80-90 s today; faster Create is a goal). Chat, and watch the dial rise when you state a wrong opinion. Drag it down or delete it, and the filmstrip shows the dose window. Export a patch and a 10-second clip.
