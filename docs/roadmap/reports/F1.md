# F1 report: clean features (SAE)

## What changed

- New `src/model_lobotomy/sae.py`: TopK SAE (hidden H, F = 8H
  features, top-k 32), MSE train loop with decoder re-normalization,
  safetensors save/load, per-token `block_out` activation cache,
  per-feature fires cache (`fires.npz` + `tokens.json`), feature
  cards, and the feature-as-`VectorEdit` helper.
- `reader.py`: `pushes_of_direction` (any hidden vector through
  gamma and the head; `pushes_toward` shares its tail, same
  numbers) and `steer_lift_vector` (unit-normed direction as a
  `VectorEdit` with scale = layer median norm, same math as lift).
- Routes: `GET /api/features`, `GET /api/feature/{layer}/{index}`,
  `POST /api/feature-lift` (default words = top-3 whole-word up
  tokens). Contracts section 7 added; `docs/reference/api.md` updated.
- Scripts: `scripts/train_sae.py`, `scripts/eval_features.py`.
- Tests: `tests/test_sae.py`, 30 tests, no model.
- Store: `store/sae/<slug>/L{12,20}/` holds weights (not
  committed), fires caches (not committed) and `config.json`
  files (committed). `.gitignore` covers the rest.

## Known gaps

- Dead share is high (L12 85%, L20 73%): plain TopK SAE with no
  revival. The gate samples live features only, so the pass
  stands, but most capacity is wasted. Follow-up: AuxK or ghost
  grads, then re-train and re-measure.
- Coherence does not beat neurons everywhere: L12 features 0.833
  vs neurons 0.894; L20 features 0.909 vs neurons 0.845. The
  gate is absolute (>= 0.6), so both layers pass, but "cleaner
  than neurons" is not shown by this metric. The metric counts
  letter-only pieces as words; a monosemanticity eval would say
  more. Follow-up with the AuxK re-train.
- Dose 1.0 gives very large lifts (hundreds to 100000x): the
  median-norm scale is strong for feature directions. Steering
  UI should offer small doses first.
- Only Llama has trained SAEs. Qwen needs its own run.
