## What changed

- `server.py` `_run_stream`: with `dial_trait`, the baseline pass runs
  through `run_stream` with a read-only `EditSet` (`Read` at the dial
  layer). The steered pass adds the same `Read` edit to its rows.
  `complete.result.dial` now carries `baseline` and `steered`: one
  `{"text", "value"}` per streamed token event of each pass. A missing
  tap reads `null`. The steered list is built from the same events as
  the stream, so streamed and final values match by construction.
  Requests without `dial_trait` use the old path unchanged.
- `server.py` replay: `_recordings` carries each recording's `dial`
  (example and sweep runs). `_replay_stream` returns it, or `null`
  when the recording has none.
- `scripts/record_sweep.py`: new `--dial-trait <family>` flag. Each
  recorded run gets `dial` in the `complete.result.dial` shape. With
  no finished Create job for the trait, the script prints why and
  records without dial.
- `docs/reference/api.md`: `/api/run` dial shape, Read-dial paragraph, and
  replay note updated.
- `tests/test_server.py`: `FakeEngine.run_stream` accepts one script
  per call (`stream_scripts`; old single script still repeats).
  `DialStreamTest` updated for the new dial shape. New `DialListsTest`
  and `DialReplayTest` hold the six spec tests.
