# UX-100x report: evidence you can turn

Builds on U4 ([U4.md](U4.md)). Design rules: [docs/DESIGN.md](../../DESIGN.md)
("Evidence you can turn", "Library", decisions log 2026-11-01).

## Results first

- **Four new parts, all checked in the browser in replay mode** on
  recorded Llama 3.2 3B runs, at 1280 px and 375 px, dark and light.
- **No new measurement.** Every number and reply on these screens is
  recorded evidence. The dial never generates.
- **"In plain words" was not run against Muse.** This server had no
  `META_API_KEY`, so the page showed the 503 hint, as designed. The
  route's cache and summary are tested with a fake Muse.

## What changed

1. **Turn the dose** (evidence page): a printed dial with one detent
   per measured dose (0 plus each PP dose). Drag, arrows, Home and End.
   For the selected dose it shows the dose in display type, a state key
   (CREATE'S DOSE, TESTED DOSE, NOT FLUENT, NO EDIT), effect, cost,
   relevance and fluency, and three recorded replies to the same
   question: no edit, the patch (first changed word in pink) and the
   plain prompt (first changed word underlined in ink). The chart ring
   follows the dial. Replies come from `pareto.samples` (2 questions)
   and the final split's base replies.
2. **How Create chose the dose**: the tuning grid (layer by dose) with
   trait, NLL rise and fluency per cell, and the reason: CHOSEN,
   QUALIFIED, NLL TOO HIGH or NOT FLUENT. Runs from before the fluency
   rule say so.
3. **Library** (shelf button): every behavior on the model, newest
   version first, with verb states, where it stands against its prompt,
   fluency at its dose, guard screens and repair state, plus one summary
   sentence.
4. **In plain words**: a button that asks Muse Spark to explain the
   report. `muse.report_summary` now includes the dose rule and the
   prompt comparison. The server caches the text keyed by those numbers,
   so a later Pareto or repair run gets a fresh explanation.

   choice) is NOT FLUENT.

   compared".
4. 375 px: no horizontal page scroll; the dial stacks above the replies.

- The dial labels sit close to the ring at phone width.

  recorded-sweep loader, not from this change.
