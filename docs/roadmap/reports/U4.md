# U4 report: evidence page v2

Spec: [specs/U4-ui-evidence-v2.md](../specs/U4-ui-evidence-v2.md).

## Results first

- **All seven gaps are closed in the app.** The evidence page now shows
  the prompt comparison (chart, verdict sentence, table), side effects
  at the chosen dose, the dose rule, every guard screen, the repair
  record with a start button, and a versions list. Create from the app
  runs the Pareto stage on the full schedule.
- **Tested in the browser in replay mode only.** The page rendered
  recorded Llama 3.2 3B runs (imported with `scripts/import_run.py`).
  The Pareto and repair buttons were not run from the browser, because
  replay mode loads no weights. Their routes are tested with fake job
  functions.
- **No JS unit tests.** The page script is one inline module. The pure
  functions (`paretoSentence`, `chartPoints`, `placeLabels`) were
  checked in the browser only.

## What changed

Backend:
- `src/model_lobotomy/followups.py`: `pareto_job` and `repair_job` (the
  logic that was in `scripts/pareto.py` and `scripts/repair_patch.py`),
  and `FollowupRunner` (one job at a time on the engine lock, status
  persisted beside the run, Stop).
- `server.py`: the report adds `pareto`, `repair`, `tuning.chosen` and
  `followups`; list items add `evidence`; new routes for Pareto, repair,
  stop and the repaired patch; `CreateRequest.pareto`.
- `create_job.py`: stages `pareto` and `guard`; `pareto` option (on for
  `full`, off for `fast`). `run_trait` reports guard progress.
- `scripts/import_run.py`: copies a CLI run into `jobs/<id>/`.
- Contract change (E1): list items gain `evidence`; the report route
  adds four fields. `docs/roadmap/contracts.md` and
  `docs/reference/api.md` record it.

Frontend (`web/index.html`):
- Side effects column: relevance and fluency at the chosen dose.
- "Compared with a plain prompt": verdict key and sentence, an SVG chart
  (the table below it is the accessible source), the drafted and label
  prompts, a note when the drafted prompt reads like a sample reply.
- Dose rule line, or a warning for doses chosen before the fluency check.
- Guard: one row per screen with its measure and state.
- Repair: what it does, each method's candidate table and status, start
  and stop, download of a repaired patch.
- Versions: every version of the behavior with its dose, fluency and
  verdicts.
- Create progress: eight stages; Pareto shows as skipped when off.
- Fixed: the Create time could read "7 min 60 s".
