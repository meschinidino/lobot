# E1 report: evidence and patch API

Owner: Claude (taken over from the backend lane, no model needed).

## What changed

- `evidence.py`: lists finished jobs as trait items (contracts section 4),
  finds report and patch files, builds the download name. File access only.
- `server.py`: `GET /api/traits`, `/api/traits/{id}/report`, `/report.md`,
  `/patch`.
- `docs/api.md`: new "Traits" section.
- `tests/test_evidence.py`: the 7 spec tests on a temporary jobs folder.

## Tests

```
uv run python -m unittest tests.test_evidence   -> Ran 7 tests, OK
uv run python -m unittest discover -s tests -t . -> OK (skipped=5)
```

## Gaps

- Not run against a real finished job yet (none exist in this container).
  Acceptance on the Mac: `curl localhost:7860/api/traits` lists the job, and
  `curl -OJ localhost:7860/api/traits/<id>/patch` saves a file that
  `patch.load_patch` loads.
- The UI already calls these routes (evidence page, Download patch, shelf rows).
