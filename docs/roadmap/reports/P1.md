## What changed

- `patch.py`:
  - `save_patch` writes `evidence_sha256` (sha256 of the
    canonical JSON of `report_card`), `members_sha256`
    (`direction.safetensors` bytes), and `lobot_version`
    (`0.1.0`, in sync with `pyproject.toml`).
  - `load_patch` recomputes both hashes and raises
    `PatchRejected` on a mismatch. Patches without hash
    fields load with `meta["unverified"]` True. Checked
    patches carry `unverified` False.
  - New helpers `canonical_json` and `sha256_hex`.
- `scripts/install_patch.py` (new):
  - `--target llamacpp` writes `control_vector.gguf` into
    `--out` through `export_control_vector` and prints the
    exact `llama-cli` flags.
  - `--target ollama` probes the installed `ollama` binary
    (`--version` plus help text, markers `control-vector`,
    `control_vector`, `controlvector`). With support it
    writes `Modelfile.lobot` plus the GGUF. Without support
    it says so plainly and exits 2.
- `scripts/verify_patch.py` (new):
  - Loads the patch (hash-checked), reads model, seed,
    trait, dose, layer, and shipped numbers from it.
  - Re-runs base vs steered generations on held-out
    final-split prompts from `prompt_bank` (same seed as
    the recipe, same frozen judge as the trait).
  - `--quick` uses 16 prompts. The default run uses the
    full 30-prompt final split.
  - Prints shipped vs measured effect with PASS or FAIL.
    Pass means the measured mean sits inside the shipped
    95% interval. Exit 0 on pass, 1 on fail, 2 on a bad
    patch or missing inputs.
- `tests/test_patch.py`: 4 new tests (hashes, two tamper
  cases, old patch).
- `tests/test_patch_install.py` (new): 5 tests (llamacpp
  GGUF plus flags, ollama exit 2, ollama snippet with a
  fake binary, verify numbers with a fake engine and
  judge, verify outside-interval fail).
- `README.md`: new "Share a patch" section.

No contract change. `contracts.md` is untouched. The E1
patch route needs no change: it serves the file as is.

Ollama finding: Ollama is not installed on this machine
(no `ollama` on PATH), so the probe reports that and the
ollama target exits 2 here.
