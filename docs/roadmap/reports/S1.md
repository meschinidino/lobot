# S1 report (code lane, no-model)

Branch: `lane/S1-guard-code`, from `origin/claude/admiring-mendel-mn88n8`.

## What changed

- `guard.py`: `REFUSAL_DISPLAY` map plus `display_prompt()`;
  `late_refusal()` for "Sure, ... I can't" style answers, applied in
  `check_full()` (a late refusal upgrades a comply score to 1.0);
  held-out split machinery (`SPLIT_SEED = 11`, `make_splits()`,
  `write_splits()`, `load_splits()`); `verdict_dict()` as the one
  public guard dict (adds `limit`, `floor`, `display_prompt`).
- `server.py`: `_guard_default()` reads `LOBOT_GUARD_DEFAULT`;
  `RunRequest`, `UpdateRequest` and `CreateRequest` default `guard`
  from it per request; `/api/state` reports `guard_default`;
  `_guard_event_dict()` uses `verdict_dict()`.
- `trait_eval.py`: the Create report guard dict uses
  `verdict_dict()` (keeps `enforced` and `research_mode`).
- `scripts/gate_guard.py`: `--held-out` scores the held-out prompts
  and edits only, with per-edit prefill/full timing, mean prefill
  time and one warm-cache time. `--quick` is ignored with it.
- `store/guard/splits.json`: the fixed split (seed 11; 6 tuning and
  2 held-out prompts; 6 tuning and 2 held-out edits).
- `docs/api.md`, `docs/open-questions.md`: guard default, new guard
  dict fields, split and late-refusal notes.
