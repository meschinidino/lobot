# TM Truth meter and head-level honesty steering

Owner: Muse (coding agent). Lane: no-model for code and tests; model
slot for probes and live checks; UI lane for the meter. Depends on:
GX (honesty screen), CH (chat). Time: three days.

## Goal

1. Show a live honesty reading in chat: does the model's internal
   state treat its own statement as true?
2. Add a head-level steering option for honesty.

Basis:
- Geometry of Truth (MIT; Marks, Tegmark): true and false statements
  separate along one direction; a mass-mean probe finds it and it
  transfers across datasets.
- Inference-Time Intervention, ITI (Harvard; Li et al.): shift a few
  attention heads along truth directions to raise truthfulness.

## Data (generated by code, fixed now)

Build true/false statements from small tables committed in
`store/truth/`:
- cities: "The city of X is in Y." (300 true, 300 false by swapping
  countries),
- comparisons: "N is larger than M." (300 + 300),
- translations or element symbols as a transfer set (200 + 200).
Train on cities, validate on comparisons, test transfer on the third.

## Probe

1. Capture the residual at the last statement token, all layers.
2. Mass-mean direction: mean(true) - mean(false), per layer. Choose
   the layer on validation.
3. Calibrate a threshold on validation. Report test accuracy once.

## Meter in chat

- After each assistant sentence, read the probe at the sentence's last
  token. Show a small meter per sentence: "the model treats this as
  true / false / unsure" with the score.
- The meter is a reading of the model, not a fact check. Say so in the
  UI.

## Head-level option (ITI)

1. Engine hook on the input of `o_proj` (per-head outputs).
2. Per head, fit a probe on the cities set; take the top K=16 heads by
   validation accuracy.
3. Shift each chosen head along its mass-mean direction, scaled by
   alpha x the head's activation std. Sweep alpha on tuning prompts
   from the honesty dev set.

## Files

- `src/model_lobotomy/truth.py`: dataset builder, probes, meter read.
- `src/model_lobotomy/engine.py`: head-output hook (`HeadEdit`).
- `scripts/truth.py fit|check|iti`.
- Routes: `GET /api/chat/{session_id}/truth`. Document it.
- Tests: dataset balance and no overlap, mass-mean on fake data, head
  hook shape on a tiny model.

## Acceptance (fixed now)

1. Unit suite passes.
2. Probe: validation accuracy >= 0.85; transfer accuracy >= 0.70.
3. Meter: on the honesty **dev** prompts with "agree with me" framing,
   sentences that agree with the false premise score lower than
   sentences that correct it, AUC >= 0.75 (judge labels the sentences).
4. ITI: honesty screen flips on the dev set drop vs no edit, with
   fluency >= 0.5 and relevance >= 0.5. Final check on the GH test set,
   once.

## Known risk

A 3B model may know few facts in the transfer set. Check base accuracy
of the model's own answers on the transfer set and drop facts it gets
wrong.
