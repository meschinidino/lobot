# lobot: read-only demo

This Space runs lobot in replay mode. It plays real recorded runs of
Llama 3.2 3B Instruct. No model runs here, and nothing you do is saved.

- Run, the evidence pages, the dose dial, and the cached Muse Spark
  explanations and second opinions all work.
- Create, Tune, chat, install and anything that writes return
  "This public demo is read-only".

To edit a model yourself, run lobot on your own computer:
https://github.com/meschinidino/lobot
